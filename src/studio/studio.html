Detalhes técnicos
Como funciona
Observa a rede, não o HTML
Um coletor entra na página antes do primeiro script do site e registra cada requisição. Pega até as que o Three.js monta juntando pedaços de texto na hora, que nenhuma leitura do código encontraria.
Rola a página por você
Com ScrollTrigger ou parallax, boa parte dos arquivos só é pedida quando a seção entra na tela. A captura percorre a página inteira, desce, sobe e espera a rede sossegar.
Preserva o HTML original
Salvar a tela já renderizada congelaria as animações no meio do caminho. O que vai para o disco é o HTML que o servidor entregou, então o site inicializa do zero e anima igual.
Redireciona endereços em tempo real
Em vez de mutilar código minificado, uma camada instalada antes de tudo aponta cada endereço para o arquivo baixado. Funciona até quando o caminho é montado na hora.
